# Neon Canvas

## Repository
https://github.com/GabrielJensen06/neon-canvas

## Description
Neon canvas will be an interactive digital art program that allows the user to create colorful glowing artwork using their mouse. The program will have a brush feature that will be editable and also the program will have particle effects giving artists a creative way to experiment with light, color, and motion.

Features

Interactive Drawing

Users can draw by dragging their mouse on the screen. Pygame will trach mouse movement and create continuous strokes. 

Customizable Brush Styles

Users will have brushes options that go from smooth and scratchy brushes and even brushes with different shapes like square or circle 

Brush Size and Color Customization

Users can adjust brush's size and select different neon colors using keyboard shortcuts. 

Eraser and Canvas Clearing

Users will be able to erase mistakes they make and clear out bits of their artwork they don't like. 

Glowing Particle Effects

Drawing will generate small, colorful particles around the brush. These particles will move and fade over time to create an animated glowing effect.

Save Artwork

Users will be able to save their finish creations and make them pngs. 

Challenges

Learning how to create different brush shapes and textures using Pygame's drawing functions and randomized patterns.

Implementing an eraser tool that removes specific parts of artwork without clearing the entire canvas.

Creating glowing and fading particle effects using transparency while maintaining smooth animation performance.

Learning how to save the digital canvas as a PNG image without including unwanted interface elements.
